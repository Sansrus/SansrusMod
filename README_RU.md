# SansrusMod

[English version](README.md)

Клиентский утилитный мод для Minecraft 26.1 на Fabric. Добавляет небольшие, но удобные изменения.

---

## Возможности

### Инвентарь и интерфейс
- **Превью карты в тултипе** — наведись на заполненную карту, чтобы увидеть её 128×128 превью, не беря в руки.
- **Превью карты в слоте** — миниатюра 16×16 прямо поверх иконки карты в слоте инвентаря.
- **Shift-перетаскивание предметов** — зажми Shift и тащи мышкой по слотам, чтобы быстро перемещать стаки.
- **Подсветка одинаковых стаков** — подсвечивает все слоты с тем же предметом, что и под курсором (зачарованные книги — по типу чар).
- **Выбор цвета подсветки** — полноценный ARGB-пикер цвета.
- **Броня рядом с хотбаром** — анимированные слоты брони слева от хотбара. Настраиваемая длительность или всегда вкл. Броня, прочность которых меньше 20 отображаются всегда.
- **Листание книг зажатием** — зажми кнопку мыши для непрерывного перелистывания страниц. Скорость настраивается.
- **Экран истории смертей** — отдельный GUI со снимками инвентаря в момент смерти. Навигация между смертями, копирование инвентаря как картинки (Ctrl+C), удаление записей (Delete).

### Чат и команды
- **Ввод команд кириллицей** — пиши команды на русской раскладке, они автоматически конвертируются в латиницу. Умный парсинг не трогает кириллицу в строковых аргументах (сообщения, никнеймы).
- **Копирование сообщений из чата** — Shift+клик по сообщению копирует текст в буфер обмена.
- **Антиспам** — объединяет повторяющиеся сообщения в одно с суффиксом `*количество`.
- **Парсер координат** — находит координаты в чате (например, `100 200 300`, `x=100 z=300`), подсвечивает их, клик — создание метки Xaero.

### Бой и выживание
- **Снимок инвентаря при смерти** — автоматически сохраняет весь инвентарь с датой и именем сервера в момент смерти. Сохраняется между перезапусками.
- **Метки смерти (Xaero)** — кликабельное сообщение с координатами смерти; клик — создание метки-черепа.
- **Защита жителей** — случайные удары по жителям блокируются (кроме удара в шифте).

### Визуальное
- **Тултип компонентов предмета** — нажми Правый Alt при наведении на предмет, чтобы увидеть все его сырые компоненты (чары, атрибуты, еда, зелья, отделка и т.д.) с цветным форматированием.

### Разное
- **Отключение кулдауна ПКМ** — убирает внутренний кулдаун использования предмета при зажатии ПКМ дольше установленного времени(в тиках).
- **Порог кулдауна ПКМ** — сколько тиков нужно зажать ПКМ, чтобы кулдаун снялся. 0 = кулдаун отключается сразу.
- **Скорость прокрутки книг** — от 1 (медленно) до 40 (быстро).

## Зависимости

- **Fabric API** 0.149.0+26.1.2
- **YACL** (YetAnotherConfigLib) — GUI настроек (встраивается при сборке)
- **ModMenu** *(опционально)* — доступ к настройкам из списка модов
- **Xaero's Minimap** *(опционально)* — требуется для меток смерти и парсера координат

---

## Установка

1. Установи **Fabric Loader** 0.19.2+ для Minecraft 26.1.
2. Положи `.jar` мода в папку `.minecraft/mods/`.
3. (Опционально) Установи ModMenu и Xaero's Minimap для полной функциональности.

Настройки через **ModMenu → SansrusMod → Настройки** или вручную в `config/sansrusmod.json`.

---

## Настройки

Все функции включаются/отключаются из GUI настроек (YACL). Xaero-зависимые опции скрыты, если миникарта не загружена.

По умолчанию большинство функций **включены**. Исключения:
- `matchingSlotHighlight` — выкл
- `chatMessageCounter` — выкл
- `coordParser` — выкл
- `mapSlotPreview` — выкл
